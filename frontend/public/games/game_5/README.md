# SmritiSetu — Game 5: "কোনটো বেলেগ? (Bhinno Ke?)"
> **Selective Attention / Visual Discrimination Cognitive Exercise for Dementia & MCI**  
> *Developed for SIH 2026 — Problem Statement 26003 (MDoNER)*

## 🌿 About the Game
"কোনটো বেলেগ? (Which Is Different?)" is a clinically grounded selective attention training exercise designed specifically for Assamese-speaking seniors with early-stage dementia or Mild Cognitive Impairment (MCI).

- **Cognitive Domain**: Selective Attention (Visual Discrimination / Distractor Filtering).
- **Format**: The patient is presented with 4 culturally familiar Assamese items (Gamosa, Jaapi, Kahor Bati / Utensils). Three of them share identical features, while one is visually distinct (the odd one out).
- **Dementia-Friendly UX**:
  - **No countdown timers & no speed pressure**.
  - **Zero failure states**: No buzzers, no red cross marks on incorrect choices. Gentle nudging only.
  - **Pronunciation assistance**: Every item card has a small speaker icon to hear its name.
  - **Gentle positive reinforcement** with native Assamese voice cues.
  - **Large accessible touch targets** (cards min 160px with generous margins).
  - High legibility typography (`Baloo Da 2`, 20pt+ font floor).
  - Warm, non-stimulating color palette (Terracotta, Paper, Soft Green, Mustard).

## 🛠 Tech Stack
- **Pure Web Technologies**: HTML5, CSS3, Vanilla JavaScript (ES6+).
- **Voice System**: Authentic Assamese narration (ElevenLabs "Zara" voice) with bilingual (AS / EN) support.
- **Silent Caregiver Telemetry**: Silently logs accuracy and attempts per round in the background without confronting the patient.

## 🚀 How to Run & Deploy
1. **Locally**: Simply double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, Safari).
2. **Deploy to Netlify / GitHub Pages**:
   - Push this repository to GitHub.
   - Connect the repository to [Netlify](https://www.netlify.com/).
   - Set publish directory to `/` (root). Site will go live immediately.
