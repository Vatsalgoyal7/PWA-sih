# SmritiSetu — Game 4: "এইটো চাব! (Etu Cabo!)"
> **Sustained Attention / Vigilance Cognitive Exercise for Dementia & MCI**  
> *Developed for SIH 2026 — Problem Statement 26003 (MDoNER)*

## 🌿 About the Game
"এইটো চাব! (Look at This!)" is a clinically grounded cognitive training game designed specifically for Assamese-speaking elderly individuals living with early-stage dementia or Mild Cognitive Impairment (MCI).

- **Cognitive Domain**: Sustained Attention (Vigilance / Detection Task).
- **Format**: A calm, peaceful Assamese river scene (Brahmaputra waters) where cultural items gently appear (Duck / হাঁহ, Boat / নাও, Golden Fish / মাছ, Lotus / পদুম, Butterfly / পখিলা).
- **Dementia-Friendly UX**:
  - **No countdown timers & no speed pressure**.
  - **Zero failure states**: No buzzers, no red cross marks.
  - **Gentle positive reinforcement** with native Assamese voice cues.
  - **Large accessible touch targets** (min 56px).
  - High legibility typography (`Baloo Da 2`, 20pt+ font floor).
  - Warm, non-stimulating color palette (Terracotta, Paper, Soft Green, Mustard).

## 🛠 Tech Stack
- **Pure Web Technologies**: HTML5, CSS3, Vanilla JavaScript (ES6+).
- **Voice System**: Pre-recorded authentic Assamese narration (ElevenLabs "Zara" voice) with bilingual (AS / EN) support.
- **Silent Caregiver Telemetry**: Tracks attention latency and interaction events in the background without confronting the patient.

## 🚀 How to Run & Deploy
1. **Locally**: Simply double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, Safari).
2. **Deploy to Netlify / GitHub Pages**:
   - Push this repository to GitHub.
   - Connect the repository to [Netlify](https://www.netlify.com/).
   - Set publish directory to `/` (root). Site will go live immediately.
