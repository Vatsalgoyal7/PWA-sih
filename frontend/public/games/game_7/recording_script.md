# 🎙️ Assamese Audio Generation Script (ElevenLabs Guide)

> **Total clips: 41** | Average length: 2–4 seconds each
> Format: `.mp3` 

This script has been updated with specific **ElevenLabs Prompt Tags** and **Emotions** to ensure the AI generates a warm, patient, and dementia-friendly voice.

### 🎛️ Recommended ElevenLabs Settings
1. **Voice Selection**: Choose an older, warm, maternal female voice (if playing an Aunt).
2. **Stability**: `30% - 40%` (Lower stability allows more natural emotion and variation).
3. **Clarity + Similarity**: `75% - 85%` (Keeps the pronunciation crisp).
4. **Style Exaggeration**: `0% - 10%` (Keep it natural, not overly cartoonish).
5. **How to prompt**: Paste the text exactly as written in the "ElevenLabs Prompt" column. The text inside the brackets `[like this]` tells the AI *how* to say the line, but it will only speak the Assamese words!
